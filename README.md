##  Методология

### 1. Применение наценки (дерево приоритетов)

Для каждой позиции правило наценки ищется сверху вниз, берётся **первое активное** на дату `2025-10-01`:

1. **Продукт** — совпадение по коду товара
2. **Бренд / Категория1**
3. **Бренд**
4. **Сегмент / Категория1**
5. **Сегмент**

Правило считается **активным**, если одновременно:
- `Активный = Да`
- `Дата начала ≤ сегодня`
- `Дата окончания` пуста или `≥ сегодня`

### 2. Универсальная формула наценки

В справочнике используются две шкалы записи:

```python
def apply_markup(zakupka, nacenka):
    if nacenka >= 1:
        return zakupka * nacenka          # множитель (Clarins: 1.03 → ×1.03)
    else:
        return zakupka * (1 + nacenka)    # процент (Vivienne Sabo: 0.59 → ×1.59)
```

### 3. Индекс цен

Для каждого конкурента:

```
Индекс = Наша цена / Цена конкурента × 100%
```

- `100%` — паритет
- `> 100%` — мы дороже
- `< 100%` — мы дешевле

Пропуски (`NaN`) у конкурентов игнорируются.

### 4. Рекомендации по скидке

- Минимальная цена с маржой 10% (маржа от цены продажи):
  ```
  мин_цена = закупка / 0.9
  ```
- Целевая цена = минимальная цена рынка × 0.99.
- Если `целевая_цена ≥ мин_цена` → можно снижать, считаем размер скидки.
- Иначе → снижение уводит маржу ниже 10%, нужно менять справочник наценок.

##  Главная находка

**В справочнике наценок значения распределены инвертированно относительно рыночной логики:**

- **Люкс (Clarins)** — наценка `1.03` (почти нулевая) → средняя маржа **3.4%**, при этом мы **дешевле рынка** и теряем прибыль.
- **Массмаркет (Vivienne Sabo)** — наценка `1.59` → средняя маржа **37.1%**, но мы **дороже рынка** и теряем клиентов.

Ценовая политика «перевёрнута»: люкс недополучает прибыль, а массмаркет не выигрывает по цене.

##  Ограничения и допущения

1. **Трактовка наценки.** В справочнике две шкалы: `≥ 1` — множитель к закупке (Clarins, 1.03), `< 1` — процент (`Vivienne Sabo, 0.59 = ×1.59`). Это допущение основано на том, что альтернативные трактовки дают отрицательную маржу.
2. **Дата фиксации.** Все расчёты выполнены на `2025-10-01` для воспроизводимости. При работе на другую дату — пересчитать активные правила.
3. **Маржа считается от цены продажи:** `(цена − закупка) / цена`. Стандартный подход в ритейле.
4. **NaN у конкурентов** (нет цены) игнорируются, а не приравниваются к нулю.
5. **Рекомендации — гипотезы.** Перед внедрением требуется проверить эластичность спроса и реакцию конкурентов.
